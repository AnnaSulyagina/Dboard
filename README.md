# Планнер — дашборд с виджетами

Учебный проект: персональный организатор на чистом JavaScript (ES6-модули) с принципами ООП.
Вдохновлён макетом «Lector Dashboard»: розовая боковая панель, светлые карточки-виджеты,
свободное позиционирование на доске.

## Функционал

**Доски**
- Одна доска («Личная доска») существует всегда по умолчанию и не удаляется.
- Доски можно создавать (+ Новая доска), переименовывать (двойной клик по названию)
  и удалять (✕ рядом с названием, кроме доски по умолчанию).
- Состояние досок и виджетов сохраняется в `localStorage`.

**Виджеты (5 типов)**
1. **Список дел** — добавление, удаление и отметка выполненных задач.
2. **Обратный отсчёт** — таймер до выбранной даты и времени, тикает в реальном времени.
3. **Заметки** — свободный текст с автосохранением и счётчиком символов.
4. **Цитата** *(внешний API №1: dummyjson.com/quotes/random)* — случайная цитата,
   кнопка «Обновить» подгружает новую; при отсутствии сети работает локальная подборка.
5. **Погода на день** *(внешний API №2: Open-Meteo)* — прогноз на конкретную выбранную дату
   для выбранного города: температура, описание, вероятность осадков.

**Режим редактирования**
- Кнопка «Режим редактирования» в шапке.
- В этом режиме виджеты можно свободно перетаскивать по доске (за шапку ⠿)
  и удалять (кнопка ✕ на карточке).
- Положение и состояние каждого виджета сохраняются автоматически.

## Архитектура (ООП)

- `UIComponent` — базовый абстрактный класс: конструктор с конфигурацией (`title`, `id`),
  `render()`, `destroy()` (снимает слушатели и убирает DOM), `minimize()`, `close()`.
- Наследники: `ToDoWidget`, `CountdownWidget`, `NotesWidget`, `QuoteWidget`, `WeatherWidget`.
- `Dashboard` — управляет коллекцией виджетов: `addWidget(widgetType)`, `removeWidget(widgetId)`,
  перетаскивание, сериализация состояния.
- `main.js` — создаёт `Dashboard`, управляет досками и кнопками интерфейса.

Слушатели событий снимаются корректно: клик-делегирование на уровне виджета отключается
в `destroy()`, таймеры (`setInterval`) очищаются в переопределённом `destroy()`.

## Инструкции по запуску

**Вариант 1 — локальный сервер (рекомендуется, проект на ES6-модулях):**

```bash
# Python 3
python -m http.server 8000
# или
npx serve .
```

Откройте в браузере `http://localhost:8000`.

**Вариант 2 — GitHub Pages (обязательное требование задания):**
1. Создайте репозиторий на GitHub и загрузите туда все файлы проекта.
2. Settings → Pages → Source: ветка `main`, папка `/ (root)` → Save.
3. Через минуту сайт будет доступен по адресу
   `https://<ваш-логин>.github.io/<имя-репозитория>/`.

> Просто открыть `index.html` двойным кликом не получится: браузер блокирует
> ES6-модули по протоколу `file://` — используйте любой из вариантов выше.

## Структура проекта

```
├── index.html             - разметка приложения
├── main.js                - инициализация, управление досками
├── js/
│   ├── UIComponent.js     - базовый класс виджета
│   ├── Dashboard.js       - управление коллекцией виджетов
│   ├── ToDoWidget.js      - список дел
│   ├── CountdownWidget.js - обратный отсчёт
│   ├── NotesWidget.js     - заметки
│   ├── QuoteWidget.js     - цитата (API №1)
│   └── WeatherWidget.js   - погода на день (API №2)
└── styles/
    ├── main.css           - layout приложения
    └── components.css     - стили виджетов
```
